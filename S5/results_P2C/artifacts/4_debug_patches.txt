## Fix 1: dataset.py - Preloading tensors to GPU when using multiple workers
**Issue**: When `num_workers > 0`, preloading tensors to GPU causes multiprocessing issues because CUDA tensors can't be shared across processes.

**Fix**: Disable tensor preloading when using multiple workers.

        """
        Determine whether to preload tensors to GPU.
        
        Returns:
            True if tensors should be preloaded, False otherwise

            print(f"Dataset size ({total_memory_mb:.1f} MB) too large for GPU preloading")
