----------------------------------------
[Implementation approach]
We will implement a complete system for reproducing the paper's physics-constrained gResNet surrogate model for urban drainage systems. The system will: 1) Parse the provided SWMM network file (Ji.inp) to extract network topology and parameters, 2) Run SWMM simulations to generate training/validation/test data (using the network's existing inflow definitions as boundary conditions), 3) Implement the gResNet architecture with physical constraint layers, 4) Train the model using the paper's hyperparameters, and 5) Evaluate performance against SWMM simulations. All data generation will be derived directly from the SWMM file without synthetic data creation.

[Anything UNCLEAR]
1) The paper uses 40 years of rainfall data from multiple gauges - we only have one SWMM file with limited inflow definitions. How should we create sufficient training data diversity? 2) The paper's System 1 has an overflow structure, but our Ji.inp has none. Should we modify the network or proceed without overflow simulations? 3) The paper uses min-max scaling per variable - do we need to handle zero-variance variables? 4) For the prior network L, the paper mentions 'dynamic mode decomposition approximation' but uses a single hidden layer NN. What should the hidden layer size be? 5) The windowed training approach: should windows overlap or be contiguous? 6) How to handle the 'spilling configuration' in SWMM - is this just setting ponding area to zero?
